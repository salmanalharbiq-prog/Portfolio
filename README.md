# Salman Alharbi — Portfolio

بورتفوليو سلمان الحربي (أخصائي ذكاء القرارات | Data Science & MLOps) — React + Vite + Tailwind.

## التشغيل محلياً

```bash
bun install   # أو npm install
bun run dev   # http://localhost:3000
```

## النشر على GitHub Pages

النشر تلقائي عبر GitHub Actions عند كل push على `main`.
مرة واحدة فقط: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

الرابط: https://salmanalharbiq-prog.github.io/Portfolio/

> ملاحظة: GitHub Pages يستضيف ملفات ثابتة فقط، لذلك `server.ts` (واجهة /api/chat) لا يعمل هناك.
> الموقع الحالي لا يعتمد عليه.
